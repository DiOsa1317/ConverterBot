# UnitMaster Bot

**UnitMaster** — это Telegram-бот для мгновенного перевода единиц измерения. Он поддерживает конвертацию валют и физических величин (длина, вес, температура).

## Roadmap: План развития

### Задача 1: Ядро конвертации
*   Конвертация валют (доллары, евро, юани, тенге, рубли).
*   Конвертация физических величин (км в мили, кг в фунты, градусы по Цельсию в градусы по Фаренгейту).
*   Распознавание сообщений формата «число из_чего в_что».
*   Команда /help для просмотра доступных вариантов перевода.
*   Понятные сообщения об ошибках при неверном формате ввода.

**Перевод валют**
> **User:** `100 usd to rub`  
> **Bot:** `100 USD = 9 250.50 RUB`

**Физические величины**
> **User:** `5 km to miles`  
> **Bot:** `5 km = 3.10686 miles`

**Обработка ошибок**
> **User:** `привет`  
> **Bot:** `Я пока умею переводить единицы. Попробуйте формат: [число] [откуда] в [куда]. Например: 10 kg to lbs`

### Задача 2: Актуальные курсы валют
*   Использование актуальных курсов валют (обновление данных каждые 6 часов).
*   При запросе справки о валютах выводится информация о дате и времени последнего обновления данных.
*   Удобные инлайн-кнопки для выбора типа перевода и конкретных единиц измерения.

### Задача 3: История переводов и кастомные единицы
*   **История конвертаций:** Возможность просмотреть последние 5 успешно выполненных переводов.
*   **Кастомные единицы:** Возможность добавить собственную единицу измерения с заданным коэффициентом конвертации относительно стандартной единицы (например, "1 my_token = 50 RUB").

#### 3.1. История последних 5 переводов
*   Доступна через кнопку `История` в главном меню или команду `/history`.
*   Отображаются только последние 5 записей. При выполнении нового перевода самая старая запись автоматически скрывается.

> **User:** *нажимает на кнопку* [ История ]  
> **Bot:**  
> **Ваша история последних переводов:**
>
> 1. `100 USD` → `9 250.50 RUB` *(07.11.2026, 14:30)*
> 2. `5 km` → `3.10686 miles` *(07.11.2026, 14:28)*
> 3. `1 kg` → `2.20462 lbs` *(07.11.2026, 12:15)*
>
> *Отображаются только последние 5 записей.*  
> [ Очистить историю ] [ В главное меню ]

**Обработка ошибок:**
> **User:** *нажимает на кнопку* [ История ] *(при первом запуске)*  
> **Bot:** Ваша история переводов пуста. Сделайте свой первый перевод, и он появится здесь!  
> [ Сделать перевод ] [ В главное меню ]

> **User:** *нажимает на кнопку* [ Очистить историю ]  
> **Bot:** История успешно очищена.  
> [ В главное меню ]

---

#### 3.2. Добавление кастомных единиц измерения
*   Позволяет создать собственную единицу измерения (например, для внутренней валюты или специфических мер).
*   Добавленные единицы сразу становятся доступны для использования в обычных переводах.

> **User:** *нажимает на кнопку* [ Мои единицы ]  
> **Bot:**  
> **Управление кастомными единицами**  
> Здесь вы можете добавить свою единицу измерения, указав, чему она равна в стандартных величинах.  
> [ Добавить новую единицу ]  
> [ Список моих единиц ]  
> [ В главное меню ]

**Сценарий добавления новой единицы:**
> **User:** *нажимает на кнопку* [ Добавить новую единицу ]  
> **Bot:** Отлично! Давайте создадим новую единицу.  
> **Шаг 1.** Придумайте название для вашей единицы (используйте только латинские буквы и нижнее подчеркивание, без пробелов).  
> *Пример: `my_token`, `cup_custom`*  
> **User:** `my_token`  
> **Bot:** Принято: `my_token`.  
> **Шаг 2.** Укажите стандартную единицу, к которой будем привязывать (например, `RUB`, `USD`, `kg`, `m`).  
> **User:** `RUB`  
> **Bot:** Отлично.  
> **Шаг 3.** Укажите курс: сколько стандартных единиц содержится в **1** вашей новой единице? (Используйте точку для дробных чисел).  
> *Пример: если 1 my_token = 50 рублей, введите `50` или `50.5`*  
> **User:** `50`  
> **Bot:** Готово! Единица `my_token` успешно добавлена.  
> Теперь вы можете использовать её в переводах.  
> *Пример использования: `10 my_token to usd`*  
> [ Добавить еще ] [ В главное меню ]

**Использование кастомной единицы:**
> **User:** `10 my_token to rub`  
> **Bot:** `10 my_token = 500.00 RUB` *(по вашему кастомному курсу)*

**Обработка ошибок (Кастомные единицы):**
> **User:** `my token` *(на шаге 1, содержит пробел)*  
> **Bot:** Название не должно содержать пробелов или спецсимволов. Пожалуйста, используйте только латинские буквы и `_` (например: `my_token`). Попробуйте еще раз.

> **User:** `пятьдесят` *(на шаге 3, вместо числа)*  
> **Bot:** Ошибка формата. Пожалуйста, введите число, используя точку для десятичных дробей (например: `50` или `50.5`).

> **User:** `RUB` *(пытается создать единицу с именем уже существующей стандартной единицы)*  
> **Bot:** Единица с названием `RUB` уже существует в системе. Пожалуйста, придумайте уникальное название для вашей кастомной единицы.

> **User:** `my_token` *(при добавлении, если такая уже есть в списке)*  
> **Bot:** Единица `my_token` уже существует в вашем списке. Хотите её обновить или удалить?  
> [ Обновить курс ] [ Удалить ] [ Отмена ]
